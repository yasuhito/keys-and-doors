# Keys & Doors

鍵と扉で自然演繹を遊ぶ、スマートフォンで遊びやすいパズルゲーム。

A phone-friendly puzzle game that turns natural deduction into keys and doors.

## Inspiration / 着想

[kihara-logic/proof-dungeon](https://github.com/kihara-logic/proof-dungeon) のアイデアに着想を得ています。同プロジェクトのコード・文章・画像は一切コピーしていません。

Inspired by the idea of [kihara-logic/proof-dungeon](https://github.com/kihara-logic/proof-dungeon). No code, text, or images have been copied from that project.
