数式と順序のみを参照し、名称・説明・物語・画像・実装は収録しない。

反例・判定問題の目標は証明すべき定理とは限らない。判定結果や解答は収録しない。

## 記号と規則

`¬A` は `A → ⊥`。量化子の `.` の右側を作用域とし、括弧を優先する。`s` は後者関数、`*` は二項関数。領域は空でない。
Iは導入、Eは除去、RAAは古典的背理法。¬I・¬Eは→I・→Eの略記でもある。=Iは反射律、=Eは等号による置換。
規則欄は解法に十分な規則の組であり、最小性や使用可能な全規則を主張しない。仮定の参照・再利用・未使用仮定の許容は共通とする。
古典論理の層でも、RAAを使わず解ける場合は省略する。5-5・5-6ではRAAを使わない。
真理値反例は古典命題論理、Kripke反例は直観主義論理、構造反例は古典一階論理の意味論を使う。
判定では証明または反例を調べる。H2-4は有限反例の探索ではなく無限Kripkeモデルを扱う。

集合定義: `A ⊆ B` は `∀x.(x ∈ A → x ∈ B)`、共通部分・和集合・補集合への所属はそれぞれ∧・∨・¬に展開する。
`X ≠ ∅` は `∃x.(x ∈ X)`。範囲量化 `∀x∈A.φ` は `∀x.(x ∈ A → φ)`、`∃x∈A.φ` は `∃x.(x ∈ A ∧ φ)`。
≤定義を指定した行だけ、`x ≤ y` を `∃z.(x + z = y)` に展開する。他の行の≤は前提に従う関係記号。
帰納法は自然数についての規則であり、算術の再帰式だけからは利用できない。16層・17層では帰納法を使わない。
補の式を使う行には、その適用に必要な∀E・→Eなどを記載する。補の再証明に必要な規則は含めない。
